# AIML Course: Python Fundamentals

This repository contains my progress and code snippets for the Artificial Intelligence and Machine Learning (AIML) course[cite: 1]. The scripts enclosed are designed to build a strong foundation in Python, which is the world's leading language for machine learning, data science, and automation[cite: 1].

## 📂 Repository Contents

The code is consolidated into a single Python script covering two main modules:

### 1. Python Fundamentals (`Python_Fundamentals.pdf`)
* **Syntax & Output**: Basic syntax and usage of the `print()` function for communication, displaying results, and debugging[cite: 1].
* **Variables & Dynamic Typing**: Understanding how variables point to objects in memory, and how Python handles dynamic type assignment (e.g., reassigning a string to an integer)[cite: 1].
* **Data Types**: Working with primitives (int, float, str, bool, NoneType) and collections (list, tuple, set, dict)[cite: 1].
* **Input Handling**: Using the `input()` function to pause the program, prompt the user, and return string data[cite: 1].
* **Functions**: Differentiating between built-in functions, external imports (like `math`), and user-defined functions[cite: 1].

### 2. String Manipulation (`PythonClass2.pdf`)
* **Formatting**: Implementing f-strings for dynamic and readable variable interpolation[cite: 2].
* **Escape Sequences**: Utilizing special characters for newlines (`\n`), tabs (`\t`), and literal backslashes (`\\`)[cite: 2].
* **Transformations & Math**: Reshaping strings using `.replace()`, `.split()`, and repeating strings via multiplication[cite: 2].
* **Slicing & Indexing**: Extracting specific characters and substrings using bracket notation and strides[cite: 2].
* **Cleaning & Searching**: Sanitizing whitespace with `.strip()` methods and searching text using `.startswith()`, `.endswith()`, and `.find()`[cite: 2].
